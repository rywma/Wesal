# Wesal Frontend

React frontend built with JavaScript and Vite.

## Current Progress

- Frontend project initialized.
- Basic login page with email and password fields.
- Required-field and email-format validation.
- Backend authentication is not connected yet.

## Requirements

- A Node.js version compatible with Vite.
- npm.

## Run Locally

From the repository root:

```bash
cd stage4/Frontend
npm ci
npm run dev
```

Open the Local URL printed in the terminal.

## Production Build

```bash
npm run build
```

The generated files are saved in `dist/`.

## Validation

- Login page renders locally.
- Password characters are masked.
- Empty required fields prevent form submission.
- Production build completed successfully.

## Deployment Settings

- Root directory: `stage4/Frontend`
- Framework: Vite
- Install command: `npm ci`
- Build command: `npm run build`
- Output directory: `dist`
